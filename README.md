# Web Bot

A sleek, dark-themed AI chatbot web interface built with pure HTML, CSS, and JavaScript.

## Features

- Clean, modern dark UI with smooth animations
- Real-time chat interface with an AI assistant
- Responsive design for desktop and mobile
- No external dependencies beyond Google Fonts

## Usage

Open `chatbot.html` directly in any modern web browser — no build step or server required.
